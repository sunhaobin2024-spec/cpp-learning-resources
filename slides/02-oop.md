# 第2章：面向对象（OOP）

---

## 1. 什么是对象？

- 对象 = 数据 + 行为
- 类 = 对象的模板
- 现实事物可以抽象成对象

---

## 2. 类与对象

```cpp
class Person {
public:
    std::string name;
    int age;
    void introduce() {
        std::cout << name << " " << age << "\n";
    }
};
```

---

## 3. 访问控制

- public：对外公开
- private：对外隐藏
- protected：继承场景使用

---

## 4. 构造函数与析构函数

- 构造函数用于初始化对象
- 析构函数用于清理资源
- 初始化列表更推荐

---

## 5. this 指针

- 指向当前对象
- 区分参数和成员变量
- 处理链式调用

---

## 6. 封装

- 把数据和行为放在一起
- 通过公共接口控制访问
- 提升代码可靠性与可维护性

---

## 7. 继承

- 复用代码
- 派生类扩展功能
- 基类/派生类关系

---

## 8. 多态

- virtual 函数
- 动态绑定
- 抽象类与纯虚函数

---

## 9. 拷贝构造与赋值运算符

- 浅拷贝问题
- 深拷贝解决方案
- Rule of Five

---

## 10. 移动语义

- std::move
- 避免不必要复制
- 提升对象传递效率

---

## 11. 练习题与参考答案

- Rectangle
- Student
- Shape 继承结构
- String 深拷贝
- Animal 多态例子

## 12. 总结

- 类和对象是 C++ 编程核心
- OOP 是工程代码的基础设计方法
