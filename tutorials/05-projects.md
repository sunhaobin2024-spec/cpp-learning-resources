# 05 实战项目与小练习

本章目标：通过小项目把学到的语法、STL 与现代特性综合应用，形成可运行的代码样例。

## 项目 1：命令行记事本（简单版）
功能：添加条目、列出条目、保存/加载到文件
技术点：文件 I/O、string、vector

实现提示：
- 使用一个 vector<string> 存储条目
- 保存时逐行写入文本文件
- 启动时读取文件恢复数据

## 项目 2：词频统计器（文本分析）
功能：统计文本文件中每个单词的出现次数并输出前 N 个
技术点：文件读写、unordered_map、排序

实现提示：
- 读入文本并拆词（注意标点处理可先简单处理）
- 使用 unordered_map<string,int> 计数
- 将结果复制到 vector<pair<string,int>> 并排序输出前 N 项

## 项目 3：简单任务调度（多线程练习）
功能：模拟任务队列，多个工作线程并发消费任务
技术点：std::thread、std::mutex、std::condition_variable、queue

实现提示：
- 生产者将任务推入队列，消费者线程等待并弹出任务执行
- 使用条件变量通知消费者

## 项目 4：算法训练模板（刷题脚手架）
功能：提供一套用于快速测试算法题的模板，包括读入、多组输入、计时等
技术点：模板化 main，常用输入优化（ios::sync_with_stdio(false)）

## 项目扩展建议
- GUI：学习 Qt 或者使用 Dear ImGui 做桌面小工具
- 游戏开发：用 SDL / SFML 做小游戏
- 系统编程：使用 POSIX 接口做网络编程练习（socket）
